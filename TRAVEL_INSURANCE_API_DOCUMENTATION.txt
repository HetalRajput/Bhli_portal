TRAVEL INSURANCE BOOKING API DOCUMENTATION
==========================================

Base URL:
---------
http://localhost:8000

Production Base URL:
--------------------
https://bhli-backend.onrender.com

Authentication:
---------------
Travel insurance booking creation requires user authentication.

Header:
Authorization: Bearer <access_token>


1. Travel Insurance Type Dropdown
=================================

URL:
GET /api/bookings/travel-insurance/types/

Purpose:
Fetch travel insurance types for dropdown.

Query Parameters:
- search: Optional. Search by insurance type name.

Example:
GET /api/bookings/travel-insurance/types/?search=Student

Success Response:
{
  "success": true,
  "message": "Data fetched successfully.",
  "count": 1,
  "data": [
    {
      "id": 3,
      "name": "Student Travel Insurance",
      "slug": "student-travel-insurance"
    }
  ]
}


2. Country Dropdown
===================

URL:
GET /api/bookings/countries/

Purpose:
Fetch countries for destination country and nationality dropdowns.

Query Parameters:
- search: Optional. Search by country name or country code.

Example:
GET /api/bookings/countries/?search=India

Success Response:
{
  "success": true,
  "message": "Data fetched successfully.",
  "count": 1,
  "data": [
    {
      "id": 101,
      "name": "India",
      "slug": "india",
      "country_code": "IN"
    }
  ]
}

Frontend Usage:
- For destination_country, send the country id.
- For nationality, send the country_code only, for example "IN".

4. Create Travel Insurance Booking
==================================

URL:
POST /api/bookings/travel-insurance/

Content Type:
multipart/form-data

Authentication:
Required

Purpose:
Submit travel insurance booking request.

Required Fields:
- service: Service id for Travel Insurance.
- full_name: Full name of traveller.
- dob: Date of birth. Format: YYYY-MM-DD.
- mobile: Mobile number.
- email: Email address.
- passport_number: Passport number.
- nationality: Country code only. Example: "IN".
- traveller_type: One of adult, child, senior_citizen.
- number_of_travellers: Number of travellers. Minimum 1.
- insurance_type: TravelInsuranceType id.
- destination_country: CountryMaster id.
- trip_start_date: Trip start date. Format: YYYY-MM-DD.
- trip_end_date: Trip end date. Format: YYYY-MM-DD.
- purpose_of_travel: Purpose of travel.
- declaration_accepted: Must be true.

Optional Fields:
- visa_type: VisaType id.
- coverage_requirements: Array of selected coverage requirements.
- other_add_ons: Any other add-ons requested by user.
- coverage_amount_required: Required coverage amount.
- passport_copy: File upload.
- visa_copy: File upload.
- other_document: File upload.
- remarks: Additional user message or notes.

Ignored From Public Payload:
These fields are office/admin fields. If frontend sends them, backend will ignore them during public booking creation.
- processed_by
- insurer_provider
- quote_premium

  "service": 18,

5. Notes For Frontend Developer
===============================

- First call /api/bookings/travel-insurance/types/ for insurance_type dropdown.
- Call /api/bookings/countries/ for destination_country dropdown.
- Use the same countries API for nationality dropdown, but send country_code in nationality.
- Call /api/bookings/visa/types/ for visa_type dropdown.
- Submit booking to /api/bookings/travel-insurance/ using multipart/form-data if files are included.
- If no files are included, JSON can be used.
- User must be logged in before submitting travel insurance booking.
